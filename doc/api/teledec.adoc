= Extension TELEDEC : contrat `Teledec::Api`
:toc: left
:toc-title: Table des matières
:toclevels: 3
:icons: font
:source-language: crystal

Contrat public de l'extension (`src/teledec/api/teledec.cr`, types dans
`types.cr`), sur le modèle de `Partiduo::Api` : acteur en premier argument,
contrôle d'accès en première ligne, vues immuables ; `ModuleDisabled` si
l'extension est inactive. Décisions : `../partiduo-app/DECISIONS.adoc`,
D-TDC-001 à D-TDC-028.

== Permissions

[cols="1,3",options="header"]
|===
|Permission |Rôle

|`teledec.return.read` |Échéances, dépôts, historique, document, accusé
|`teledec.return.prepare` |Préparer, contrôler, exporter la balance (exige aussi `accounting.report.read`, ou `accounting.vat.declare` pour la TVA ; sans la Comptabilité, `liberal.register.read` pour la 2035)
|`teledec.return.transmit` |Transmettre, actualiser, noter l'issue d'un dépôt fait hors de Partiduo
|`teledec.settings.manage` |Régime, options, identifiants de l'API
|===

== Paramètres

* `settings(actor) : SettingsView` — régime d'imposition (`TAX_SYSTEMS` :
  `is_rsi`, `is_rn`, `bic_rsi`, `bic_rn`, `bnc`, `sci`), régime de TVA
  (`VAT_SYSTEMS` : `ca3_monthly`, `ca3_quarterly`, `ca12`, `none`), option
  greffe, comptes (préfixe → nature, `DAS2_NATURES`) et seuil de la DAS2,
  environnement, identifiant (`login`, rendu aux seuls titulaires de
  `teledec.settings.manage`, vide sinon), `key_stored`, transport branché.
* `SettingsView#accounting` (Comptabilité active), `#kinds` (sortes
  proposées), `#tax_systems` (régimes proposés) : sans la Comptabilité,
  `false`, `["liasse"]`, `["bnc"]`, et `#tax_system` vaut `bnc` si aucun
  régime n'est choisi (D-TDC2-001).
* `update_settings(actor, SettingsInput)` ; sans la Comptabilité, un
  régime autre que `bnc` est refusé (`tax_system`,
  `teledec.errors.accounting_required`).
* `save_credentials(actor, CredentialsInput(login, api_key, env, email, siret, renew_callback_token))` —
  `login` et `api_key` : identifiant et secret du client OAuth2 de TELEDEC,
  chiffrés ; vérifiés par le transport s'il est branché (un jeton est
  demandé) ; secret vide : secret enregistré gardé
  (`teledec.errors.credentials.unreadable` s'il ne se déchiffre plus) ;
  `email` : compte TELEDEC de l'entreprise (vide : email de la société,
  `teledec.errors.credentials.email`) ; `siret` : 14 chiffres ou vide
  (`teledec.errors.credentials.siret`), commençant par le SIREN de la
  société (`teledec.errors.credentials.siret_siren`). Crée le jeton des
  rappels s'il n'y en a pas, le renouvelle si `renew_callback_token`.
  `clear_credentials(actor)`.
* `SettingsView#email`, `#siret`, `#callback_path` (chemin des rappels,
  jeton compris), `#callback_url` (adresse complète en https sous
  l'adresse publique de l'instance, vide si elle est inconnue) : vides
  pour qui n'a pas `teledec.settings.manage`.

== Déclarations

[cols="1,2,2",options="header"]
|===
|`kind` |Saisie (`PrepareInput`) |Document

|`liasse` |`fiscal_year_id` |balance avant clôture, balance N-1, identité ; 2035 : cases et empreinte de `Liberal.tax_return`
|`greffe` |`fiscal_year_id`, `confidential` |balance, identité
|`is_2571` |`fiscal_year_id`, `number` (1 à 4), `amount` |montant de l'acompte (euros)
|`is_2572` |`fiscal_year_id`, `amount` (défaut : solde du 695) |impôt, acomptes transmis, solde
|`vat_ca3`, `vat_ca12` |`vat_return_id` (déclaration close) |cases non nulles arrondies à l'euro, totaux recalculés sur les cases arrondies (`VatTotals`)
|`das2` |`year` |bénéficiaires au-delà du seuil, montants TTC par nature
|===

* `schedule(actor, fiscal_year_id) : Array(DeadlineView)` — déclarations
  attendues, échéance, dépôt existant, déclaration de TVA close de la
  période.
* `prepare(actor, input) : Result(FilingView)` — crée ou remet à jour le
  dépôt (clé `liasse:<exercice>`, `vat_ca3:<début>`, `das2:<année>`,
  `is_2571:<exercice>:<n>`…) ; refus si déjà transmis ou accusé
  (`teledec.errors.filing.locked`).
* `check(actor, id)` — recalcule : `teledec.controls.changed` si le
  document a changé depuis la préparation.
* `transmit(actor, id, base_url = nil)` — adresse de rappel envoyée à
  TELEDEC (`auth.url`) : sous `base_url` si elle est donnée, sinon sous
  l'adresse publique de l'instance (`Callbacks.instance_base_url` :
  domaine de la société, `PARTIDUO_HOST`, premier de
  `MARTEN_ALLOWED_HOSTS`), jamais tirée de la requête ; `https://`
  seulement, sinon pas d'`auth.url` (suivi par `refresh`). Refus : statut, document changé, contrôle
  bloquant, transport absent (`teledec.errors.transport.unavailable`),
  identifiants absents ou illisibles (`teledec.errors.credentials.missing`,
  `.unreadable`), erreur du transport (notée dans l'historique), dépôt
  préparé de nouveau pendant l'envoi (`teledec.errors.filing.concurrent`,
  référence TELEDEC notée dans l'historique). Clé d'idempotence :
  `partiduo-<dépôt>-<rang>-<empreinte>`. Toute transition prend le verrou
  des dépôts et relit le dépôt (DECISIONS D-TDC-013).
* `refresh(actor, id)`, `refresh_all(actor)` — état chez TELEDEC
  (`FilingView#remote_status`, `REMOTE_STATUSES`), accusé (pièce jointe du
  socle) ou rejet (motif : erreurs de la DGFiP) ; les comptes-rendus d'un
  paiement ou d'un envoi précédent (autre référence) ne font pas foi ;
  `refresh_all` isole chaque dépôt.
* `callback(presented_token, body) : String` — rappel de TELEDEC, sans
  acteur, authentifié par le jeton des rappels ; rend `unauthorized`,
  `invalid`, `ignored` ou `ok` ; idempotent sur l'identifiant de la
  déclaration ; rattaché par la référence (par `declarationId` seulement
  sans référence ; référence inconnue : `ignored`) ; rappels de paiement
  ou d'un autre type de déclaration : `ignored` ; `formulairesStatus`,
  s'il est donné, fait seul foi (`Sent` : en attente) ; `ModuleDisabled`
  si l'extension est inactive. Servi par
  l'interface sur `CALLBACK_PATH` (`/hooks/TELEDEC/callback`, hors de
  `/ext/`, sans session ni jeton CSRF ; jeton en `Basic`, `Bearer` ou
  paramètre `token` ; 413 si `Content-Length` dépasse
  `Callbacks::MAX_BYTES`).
* `record_outcome(actor, id, OutcomeInput)` — repli : transmis (référence),
  accusé (fichier facultatif), rejeté (motif obligatoire) ; une seule
  transaction : une pièce refusée laisse le dépôt préparé.
* `FilingView#remote_id` : clé de suivi `<formulaire>:<siren>:<fin>[:<échéance>]` ;
  `#remote_url` : page de la déclaration chez TELEDEC, à ouvrir par
  l'utilisateur pour vérifier et envoyer ; `#declaration_id` : identifiant
  chez TELEDEC.
* `filings(actor, fiscal_year_id?) : Array(FilingSummaryView)` (en-tête,
  statut, contrôles ; document non relu), `filing(actor, id) : FilingView`,
  `events(actor, id)`.
* `balance_file(actor, fiscal_year_id)`, `export_file(actor, id)`,
  `receipt_file(actor, id)`. Sans la Comptabilité, `balance_file` lève
  `Teledec::Api::AccountingRequired` (sous-classe de `ModuleDisabled`,
  clé `teledec.errors.accounting_required`).

*Libéral sans Comptabilité* (module `liberal` seul, D-TDC2-002) : seule la
`liasse` d'un régime BNC se prépare, à partir de la 2035 de
`Liberal.tax_return` (cases, empreinte, `details.source = "liberal"`), sans
balance ; toute autre sorte échoue sur `teledec.errors.accounting_required`
(erreur de base), sans lecture de `Partiduo::Api::Accounting`.

`das2` : `year` de 2000 à 2100 (`teledec.errors.year.invalid`).

`FilingView#ready?`, `FilingSummaryView#ready?` : aucun contrôle bloquant (`ControlView#error?`).

== Transport

[source]
----
abstract class Teledec::Transport
  abstract def name : String
  abstract def check(credentials : Credentials) : Nil                            # TransportError
  abstract def submit(credentials : Credentials, submission : Submission) : Submitted # remote_id, url, remote_status
  abstract def status(credentials : Credentials, remote_id : String, reference : String = "") : RemoteStatus  # pending, acknowledged, rejected
end

Teledec::Transports.current = … # Teledec::HttpTransport par défaut ; nil : repli
----

`TransportError#key` est une clé i18n (`teledec.errors.transport.*` :
`credentials`, `refused`, `unreachable`, `source`, `account`, `email`,
`siret`, `invalid`, `unsupported`, `das2_nature`). `Credentials#to_s` masque le secret.

=== Adaptateur réel `Teledec::HttpTransport`

[cols="1,3",options="header"]
|===
|Échange |Traduction

|Jeton |`POST https://auth.partners.teledec.fr/oauth2/token`, `Basic`,
`grant_type=client_credentials`, scopes `stage/…` (environnement de test)
ou `prod/…` ; cache jusqu'à `expires_in` moins une minute ; 401 : nouveau
jeton, appel rejoué une fois.
|Liasse |`POST /service/liasse` (texte) : `#SOURCE`, `#VERSION`, `#EMAIL`,
`#NOM`, `#SIRET` (obligatoire ici), `#CATEGORIE-FISCALE` et
`#REEL-NORMAL-OU-SIMPLIFIE` (d'après les formulaires), dates d'exercice,
forme juridique, adresse, `#AFFICHAGE-BOUTON-ENVOYER`, `#REFERENCE` ;
balance `compte;libellé;0;0;débit;crédit;solde débit;solde crédit` ;
2035 préparée en bloc JSON `zones_formulaires`. Réponse : URL de la liasse.
|TVA, DAS2, IS |`POST /service/declaration-marque-blanche` (JSON `auth`,
`identity`, `period`, bloc `3310CA3`, `3517SCA12`, `DAS2`, `2571`, `2572`) ;
codes par millésime (`Remote::Formats`) ; lien demandé
(`retournerLien`). Une case de TVA sans code bloque la préparation
(`teledec.controls.box_unmapped`).
|Suivi |`GET /service/declaration-status` (404 : pas encore de
déclaration) ; accepté ou rejeté : compte-rendu le plus récent
(`compteRendus`, sinon `/service/recuperation-liste-compterendus`) — accusé
PDF, erreurs de la DGFiP (`declarationErreurs`).
|Greffe |pas de route documentée : `teledec.errors.transport.unsupported`.
|===

États : `NotCompleted`, `ReadyToBeSent`, `Sent` → transmis (en attente) ;
`OK`, `Accepted`, `CompleteWithWarnings` → accusé ; `ERREUR`, `Rejected`,
`CompleteWithErrors` → rejeté (casse indifférente).

== Document transmis

`Teledec::Payload` (schéma `partiduo-teledec/1`) : `kind`, `forms`,
`identity`, `period_from`, `period_to`, `number`, `balance`,
`previous_balance`, `boxes`, `das2`, `details`. Montants en texte décimal ;
empreinte SHA-256 du JSON.

== Base

Tables `teledec_settings` (ligne unique ; email du compte TELEDEC, SIRET,
jeton des rappels chiffré), `teledec_filing` (suivi chez TELEDEC :
`remote_reference`, `remote_status`, `remote_url`, `declaration_id` ; valeurs
contrôlées, clés étrangères vers `core_attachment` (accusé),
`core_fiscal_year` et `auth_user` (auteurs, `ON DELETE SET NULL`), déclencheur
`teledec_filing_guard` : document intangible une fois transmis, accusé
définitif), `teledec_filing_event`.
